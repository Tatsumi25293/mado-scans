# MADO Scans 🌌

منصة مانجا ومانهوا عصرية وفاخرة مصممة بواجهة زجاجية داكنة تحاكي فلسفة **Apple Liquid Glass**، متوافقة ومتجاوبة بالكامل مع شاشات الهواتف وأجهزة الكمبيوتر (PC).

---

## ✨ المميزات الرئيسية (Key Features)

- **تصميم Apple Liquid Glass الفاخر**:
  - خلفيات OLED داكنة مطفية (`#07080b`).
  - تأثيرات زجاجية ثلاثية الأبعاد (`backdrop-blur-3xl`) مع حواف زجاجية رفيعة وهادئة.
  - لمسات برتقالية مرجانية دافئة (`#e64626`).
- **شريط تنقل عائم (Floating Dock)**: متواجد على نسخة الكمبيوتر والهاتف بستايل Apple وتوهج تفاعلي.
- **سلايدر بطاقات الاقتراحات الكبرى (Hero Suggestions)**: بطاقات سينمائية عريضة مع أسهم تنقل جانبية وأختام قفل وشارات مشاهدة.
- **قسم التوب تريند (Top Trending)**: تراكب بطاقات احترافي ومؤشر عداد رأسي.
- **عارض فصول احترافي (Webtoon Strip Reader)**: قراءة سلسة ومستمرة للفصول بشريط تحكم عائم.
- **لوحة إدارة سرية متكاملة (Discreet Admin Console)**:
  - رفع أغلفة المانهوا والبانرات مباشرة من ملفات الجهاز (PNG, JPG, WEBP).
  - رفع صفحات الفصول دفعة واحدة (Multi-file upload) مع ترتيب أوتوماتيكي للأرقام.
  - تخزين محلي غير محدود عبر تقنية **IndexedDB** لحفظ الصور عالية الدقة.
  - إدارة كلمة المرور والبيانات.
- **تصفح حسب التصنيفات (Genre Explorer)**: شريط كبسولات لتصفية الأعمال بسرعة وسلاسة.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend**: React 19
- **Bundler & Build Tool**: Vite 8
- **Styling**: Tailwind CSS v4
- **Icons**: Lucide React
- **Storage**: IndexedDB & LocalStorage Hybrid

---

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الحزم**:
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير**:
   ```bash
   npm run dev
   ```

3. **بناء النسخة الإنتاجية**:
   ```bash
   npm run build
   ```

---

## 🔐 لوحة الإدارة (Admin Access)

- يمكن الدخول السري عبر الرابط المباشر: `/#admin`
- أو النقر المزدوج السريع على شعار **MADO** في الترويسة.
- أو عبر تبويب **حسابي** ثم اختيار *"تسجيل دخول الإدارة"*.
- كلمة المرور الافتراضية: `mado`
